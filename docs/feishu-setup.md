# 飞书机器人配置教程（全中文菜单）

> 公众号「AI之境」｜pi-bot-cn：大陆可自建的 Grok Bot 平替
>
> 全程只用**长连接**：服务器主动连飞书，不需要公网 IP、域名或 HTTPS 证书，也**不用**对外开任何端口。

如果你的飞书开放平台是英文界面：点右上角头像旁的语言切换，选「简体中文」，下面的菜单名就都对得上了。

---

## 第 1 步：创建应用

1. 打开 **飞书开放平台**（open.feishu.cn），右上角点 **「开发者后台」**。
2. 点 **「创建企业自建应用」**，名称填 `pi-bot-cn`（随意），描述填「我的私人助手」，选个图标，点 **「创建」**。

## 第 2 步：拿到凭证，写进服务器（不要发给任何人）

1. 左侧菜单 **「凭证与基础信息」**，能看到 **App ID** 和 **App Secret**。
2. 登录服务器，用编辑器写入 env 文件（**不要**把它们粘贴到任何聊天窗口里，包括 AI）：

   ```bash
   mkdir -p ~/.config/pi-bot-cn && nano ~/.config/pi-bot-cn/env
   # 加三行（等号后面换成你自己的）：
   # FEISHU_APP_ID=cli_xxxxxxxx
   # FEISHU_APP_SECRET=xxxxxxxx
   # FEISHU_DOMAIN=feishu
   chmod 600 ~/.config/pi-bot-cn/env
   ```

   保存后网关会**自动重启**并连上飞书（`pi-bot-cn-env.path` 在盯着这个文件）。

## 第 3 步：添加机器人能力

左侧 **「添加应用能力」** → 找到 **「机器人」** → 点 **「添加」**。

## 第 4 步：开通权限

左侧 **「权限管理」** → **「开通权限」**，搜索并开通下面几项（括号里是权限代码，搜代码更快）：

| 权限名称 | 代码 | 用途 |
|---|---|---|
| 读取用户发给机器人的单聊消息 | `im:message.p2p_msg:readonly` | 收你的私聊 |
| 获取与发送单聊、群组消息 | `im:message` | 回复、更新流式卡片 |
| 以应用的身份发消息 | `im:message:send_as_bot` | 主动发消息 |
| 接收群聊中 @机器人消息事件（可选） | `im:message.group_at_msg:readonly` | 群里 @ 它时才需要 |

## 第 5 步：先确认服务器已经连上

飞书要求：**保存「长连接」之前，你的程序必须已经连上**。在服务器上执行：

```bash
curl -s 127.0.0.1:8787/health          # 看到 "feishu":{"state":"connected" 就对了
grep FEISHU_WS_CONNECTED ~/pi-bot-cn-data/logs/gateway.jsonl | tail -1
```

## 第 6 步：事件订阅用长连接

1. 左侧 **「事件与回调」** → **「事件配置」** 页签。
2. **「订阅方式」** 点编辑 → 选 **「使用长连接接收事件」** → **「保存」**。
3. 点 **「添加事件」** → 搜 **「接收消息」** → 勾选 **「接收消息 v2.0」**（`im.message.receive_v1`）→ **「确认添加」**。

## 第 7 步：卡片回调也用长连接

1. 同一页切到 **「回调配置」** 页签。
2. **「订阅方式」** 选 **「使用长连接接收回调」** → **「保存」**。
3. 点 **「添加回调」** → 勾选 **「卡片回传交互」**（`card.action.trigger`）→ **「确认添加」**。

   这样回复卡片上的 **「停止」按钮**才能用。

## 第 8 步：发布版本

1. 左侧 **「版本管理与发布」** → **「创建版本」**。
2. 版本号填 `1.0.0`；**「可用范围」** 只选你自己；更新说明随便写。
3. 点 **「保存」** → **「申请线上发布」**。企业自建应用、管理员就是你自己时，一般秒过、免审核。

> 以后每次改了权限、事件，都要再发一个新版本才生效。

## 第 9 步：开始聊天

打开飞书客户端，搜索 `pi-bot-cn`，进入私聊，发「你好」。

## 第 10 步：锁定主人（强烈建议）

还没锁定时，网关只响应私聊，并把发消息人的 open_id 记到日志里。拿到后写进 env，从此只听你一个人的：

```bash
grep feishu_owner_hint ~/pi-bot-cn-data/logs/gateway.jsonl | tail -1     # 找 "senderOpenId":"ou_..."
echo 'PI_BOT_OWNER_OPEN_IDS=ou_你的open_id' >> ~/.config/pi-bot-cn/env      # 网关会自动重启
```

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 保存长连接时提示「未检测到应用连接」 | 网关没跑或凭证填错。`systemctl status pi-bot-cn`、`curl -s 127.0.0.1:8787/health` 看 `feishu.state` 和 `lastError` |
| 发消息机器人不理 | 版本没发布 / 可用范围没包含你 / 没加「接收消息 v2.0」事件；或已锁定主人但 open_id 不对（日志里有 `feishu_gate_drop`） |
| 点「停止」没反应 | 没加「卡片回传交互」回调，或加完没重新发布版本 |
| 回复只出现一半就不动了 | 看日志 `outbox_retry`：飞书接口限流或网络抖动，Outbox 会自动重试补发 |
